🧰 Tech Stack: Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Jupyter Notebooks, HTML (for report export)

📚 Dataset Source

Kaggle - 120 Years of Olympic History - (https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)

▶️ How to Run

Clone the repo
git clone https://github.com/SriVarshini277/OlympicsDataAnalysis.git

Install dependencies
pip install -r requirements.txt

Open Jupyter Notebook or run Python scripts for analysis.
